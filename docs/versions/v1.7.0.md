# Версия v1.7.0

Дата: 2026-06-29

## Смысл Версии

Версия `v1.7.0` добавляет сборку Origin-отчета из интерфейса серии, уточняет работу со спектральными сетками напряжений и вводит отдельный оранжевый статус для пикселя, который достиг лимита тока во время съемки спектра.

## Основные Изменения

- В меню серии появилась кнопка `Составить отчет`.
- Окно отчета показывает подсерии со спектрами и позволяет выбрать, какой пиксель попадет в отчет, если для подсерии снято несколько спектральных пикселей.
- Для спектров отчета задаются начало, конец и шаг напряжения.
- В общем режиме одна сетка напряжений применяется ко всем выбранным пикселям и проверяется по пересечению доступных напряжений.
- В индивидуальном режиме для каждого пикселя задается своя сетка, а общий спектральный график строится на максимальном общем напряжении.
- `scripts/build_report_origin_workbook.py` теперь умеет фильтровать спектры по заданной сетке и принимает `--spectrum-voltage-grid PIXEL=START:STOP:STEP`.
- Если при съемке спектра ток достигает лимита, пиксель получает статус `NEEDS_REVIEW` и отображается оранжевым как `требует уточнения`.
- Верхние четверти на карте подложкодержателя подняты выше, чтобы не налезать на нижние.

## Совместимость

Формат существующих журналов и файлов измерений не меняется. Новый статус `NEEDS_REVIEW` записывается только для спектрального измерения, остановленного по лимиту тока. Прямой `.opju`-вывод отчета по-прежнему требует доступный OriginPro Python API `originpro`; для проверки структуры можно сохранять отчет в `.xlsx`.
