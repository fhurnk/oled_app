# Версия v1.5.4

Дата: 2026-06-25

## Смысл Версии

Версия `v1.5.4` добавляет правила ведения GitHub-релизов для будущих чатов Codex и улучшает удобство измерений: подбор времени интегрирования спектра, запоминание режима графика ВАЯХ и стартовые размеры дополнительных окон.

## Основные Изменения

- Добавлен `AGENTS.md` с обязательным workflow для Codex: менять `APP_VERSION`, вести `CHANGELOG.md`, добавлять `docs/versions/vX.Y.Z.md`, пушить commit, tag и создавать GitHub Release для каждой версии.
- Добавлен `docs/GITHUB_RELEASE_WORKFLOW.md` с практическим порядком публикации.
- При измерении спектров найденное хорошее `T_int` становится начальным для следующей точки. Если первая итерация подбора была saturated, следующая точка стартует уже с подобранного безопасного времени.
- Выбор формы live-графика ВАЯХ сохраняется между измерениями.
- Окна ВАЯХ, спектров, стабильности, настроек и live-прогресса открываются с размером, рассчитанным по содержимому.

## Совместимость

Формат журналов и файлов измерений не менялся. В `oled_app_settings.json` может появиться новая секция `ui` для пользовательских предпочтений интерфейса.
