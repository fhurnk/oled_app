# v1.9.0-alpha

Дата выпуска: 2026-07-26

## Главное

Экспериментальная версия добавляет калибровку светимости по спектру, пересчёт уже снятых серий, очередь спектров и быстрый просмотр формы ВАЯХ прямо с карты пикселей.

## Спектральный пересчёт

- Действие запускается отдельной кнопкой `Пересчитать спектр в отдельный файл`.
- Для каждой спектральной точки используется лист `Processed counts per s`.
- После штатного вычитания плоского фона спектр нормируется на максимум; затем применяется множитель `CIE V(λ) / BPW34(λ)` и численное интегрирование.
- Нормированные интегралы выбранного пикселя сравниваются при разных токах фотодетектора.
- Медиана пригодных интегралов назначается спектральным интегралом всей физической четверти; в книге результата сохраняются минимум, максимум и относительный разброс.
- Для другого пикселя этой четверти отдельная кнопка предлагает применить сохранённый интеграл либо заменить калибровку расчётом по новому пикселю.
- Результат, ток фотодетектора, прежняя светимость по R/G/B, новая светимость, интегралы и отклонения записываются в отдельный `SPECTRAL_RECALC_<pixel>_<time>.xlsx`.
- Снятый Spectrum XLSX не изменяется и автоматический пересчёт после измерения не выполняется.

Таблица CIE/BPW34 выделена в `oled_app/data/spectral_sensitivity.csv`. На предоставленных тестовых спектрах отношение зелёного и красного интегралов составляет `3,466` при ручном ориентире `3,49`.

## Коэффициенты Светимости

- `geometric_conversion_coefficient` умножает цветовые коэффициенты фотодиода R/G/B.
- До калибровки применяется прежняя формула `L = I_photodiode × RGB_coefficient × geometric_coefficient`.
- После калибровки применяется `L = I_photodiode × quarter_spectral_integral × integral_coefficient × geometric_coefficient`.
- Таким образом, произведение спектрального интеграла четверти и `integral_conversion_coefficient` заменяет R/G/B, а ток фотодетектора остаётся обязательным множителем.
- Применённые коэффициенты записываются в метаданные новых измерений и отдельной книги пересчёта.

## Пересчёт Существующей Серии

Кнопка `Пересчитать мкА → кд/м²` обновляет светимость в книгах ВАЯХ, спектров и стабильности открытой серии. Для откалиброванной четверти используется спектральный интеграл с интегральным коэффициентом вместо R/G/B; для остальных четвертей сохраняется выбор по цвету.

Если raw CSV отсутствует, приложение восстанавливает его из соответствующих листов XLSX. Книга сначала сохраняется во временный файл и только после успешной записи атомарно заменяет прежнюю. Эта операция не запускает CIE/BPW34-пересчёт.

## Очередь И Миниатюры

- На карте пикселей доступен флажок ожидаемого спектра.
- Режим спектров `Очередь серии` сортирует отмеченные пиксели перед остальными.
- После успешного спектра флажок снимается.
- После ВАЯХ создаётся миниатюра графика без числовых подписей.
- При наведении на пиксель карта показывает миниатюру, чтобы быстро оценить форму кривой и признаки шунта.
