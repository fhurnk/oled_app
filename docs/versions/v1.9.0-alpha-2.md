# v1.9.0-alpha-2

Дата выпуска: 2026-07-27

## Главное

Вторая alpha-сборка улучшает рабочий процесс очереди спектров: отметки перенесены из тесной карты пикселей в таблицу дат, подложку можно поставить в очередь целиком, а последовательную съёмку можно начать с произвольного пикселя.

## Очередь Спектров

- В столбце `Спектры` до измерения показывается кликабельный флажок `поставить` или `в очереди`.
- После успешного снятия спектра флажок исчезает, а в этой же ячейке показываются дата и максимальная интенсивность.
- На карте подложкодержателя флажки больше не рисуются.
- Кнопки над таблицей добавляют в очередь всю подложку выбранного пикселя или снимают с неё отметки.
- Пиксели с уже снятым спектром пакетная операция не изменяет.
- Журнал обновляет несколько отметок подложки за одну операцию записи XLSX.

## Последовательная Съёмка Подложки

- Режим `Вся подложка последовательно` показывает выбор подложки и стартового пикселя.
- Последовательность начинается с выбранного пикселя и, как серия ВАЯХ, не возвращается к более ранним позициям.
- Физический порядок пикселей подложки не меняется из-за приоритетов общей очереди.
- Переключатель `Только отмеченные пиксели этой подложки` позволяет последовательно снять именно очередь выбранной подложки.
- Для каждого пикселя по-прежнему отдельно подставляется его напряжение открытия; ручное стартовое напряжение остаётся общим для последовательности.
