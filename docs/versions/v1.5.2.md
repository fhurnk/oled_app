# Версия v1.5.2

Дата: 2026-06-25

## Смысл Версии

Версия `v1.5.2` фиксирует текущую рабочую ветку приложения после добавления физического пересчёта, обновления live-графика ВАЯХ, изменения обработки спектров и подготовки проекта к хранению в GitHub.

## Основные Изменения

- Добавлены настройки площади пикселя и коэффициента перевода фототока в светимость.
- Live-график ВАЯХ переключается между сырыми и пересчитанными величинами.
- Excel-файлы ВАЯХ, спектров и стабильности получают колонки `mA/cm^2` и `cd/m^2`.
- Основная обработка спектров стала `raw - средний фон`.
- Добавлена документация структуры проекта и история обновлений.
- Добавлен `.gitignore` для исключения `OLED_series/`.

## Совместимость

Старые серии можно открывать, но новые измерения будут сохраняться по обновлённой структуре папок и с расширенным набором колонок.

## Репозиторий

Целевой репозиторий для публикации: `OLED_meas`.

В репозиторий следует добавлять весь проект, кроме локальных результатов измерений `OLED_series/`.
