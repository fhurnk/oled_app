# Версия v1.8.0-alpha.2

Дата: 2026-07-15

Статус: экспериментальная GitHub prerelease.

## Смысл версии

`v1.8.0-alpha.2` исправляет отображение LiveView на основном компьютере после первой проверки камеры на реальном Raspberry Pi. Управление камерой, полноразмерное фото и сохранение preview-кадра уже работали, но непрерывная отрисовка могла выдавать `[Errno 22] Invalid argument` для корректных JPEG.

## Исправлено

- JPEG полностью загружается из памяти до передачи изображения в Tk, поэтому ленивый декодер Pillow больше не зависит от уже закрытого временного потока.
- `ImageTk.PhotoImage` явно использует Tcl-интерпретатор canvas окна камеры.
- При отказе `LANCZOS` для отдельного кадра масштабирование повторяется через `BILINEAR`.
- Повторяющаяся ошибка одного этапа выводится один раз и затем через каждые 50 повторов вместо записи в лог на каждом кадре.
- Сообщение указывает этап сбоя: декодирование JPEG или отрисовка Tk.

## Проверено

- unit-тесты HTTP-клиента и декодирования LiveView;
- компиляция модулей камеры;
- декодирование реального сохранённого preview JPEG `1024×680`;
- создание `ImageTk.PhotoImage` из реального preview в используемом окружении Windows.

## Требует проверки на оборудовании

- непрерывный LiveView после обновления приложения;
- запись и штатное завершение MP4 на Raspberry Pi.
