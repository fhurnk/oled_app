# v1.8.4

Дата выпуска: 2026-07-23

## Главное

- Окно камеры позволяет выбирать ISO, выдержку, диафрагму и экспокоррекцию для полноразмерного фото, если подключённая камера действительно предоставляет эти параметры для записи.
- Список возможностей строится при инициализации из `gphoto2 --list-config` и `gphoto2 --get-config`; значения не зашиты под конкретную модель Canon.
- Перед снимком сервис проверяет выбранный путь и значение по результатам опроса, применяет настройку и читает её обратно. Несовпадение останавливает съёмку с понятной ошибкой.
- Выбор экспозиции сохраняется отдельно от JPEG-качества и восстанавливается при следующем подключении, если значение всё ещё поддерживается камерой.

## Использование

1. Установите на камере режим, разрешающий ручное изменение нужных параметров; для полного управления рекомендуется `M`.
2. В окне камеры нажмите `Подключиться` или `Переинициализировать камеру`.
3. Выберите доступные значения в блоке `Экспозиция полноразмерного фото`.
4. Нажмите `Сделать фото камерой` или запустите сопровождаемый сценарий измерения.

После изменения положения диска режимов снова нажмите `Переинициализировать камеру`, потому что набор доступных параметров и вариантов может измениться.

## Raspberry Pi

Для этой версии нужно скопировать обновлённый `raspberry_camera_service/camera_service.py` на Raspberry Pi и перезапустить службу:

```bash
sudo systemctl restart oled-camera
sudo systemctl status oled-camera
```

Физическая Canon EOS 5D Mark II требует контрольной проверки доступных значений на стенде: конкретный набор зависит от режима камеры, прошивки и версии libgphoto2.
