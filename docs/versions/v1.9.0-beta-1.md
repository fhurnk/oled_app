# v1.9.0-beta-1

Дата выпуска: 2026-07-29

## Главное

Линейная спектральная калибровка больше не экстраполируется в область, где светодиод ещё не открылся. Для каждой точки и каждого пикселя приложение сравнивает напряжение с сохранённым `Opening voltage (V)`.

## Правило Расчёта

- При `V < Opening voltage` используется прежний цветовой коэффициент:

  `L = Iфд × R/G/B × Kгеом`.

- При `V ≥ Opening voltage` для линейно откалиброванной четверти используется:

  `L = Iфд × (a × V + b) × Kинт × Kгеом`.

- Порог берётся отдельно для каждого пикселя, хотя коэффициенты `a` и `b` задаются одним калибровочным пикселем для всей четверти.
- Если в журнале пикселя ещё нет напряжения открытия, используется минимальное напряжение спектра, по которому была построена калибровка.
- Медианная и робастная медианная модели не ограничиваются этим порогом; изменение относится только к линейной модели.

## Калибровка И Отчёт

- Точки ниже напряжения открытия не участвуют в линейной аппроксимации.
- Отдельный файл `SPECTRAL_RECALC_*.xlsx` содержит напряжение активации линейной модели.
- Для каждой спектральной точки отчёт показывает `Linear calibration active`: ниже порога интеграл модели оставлен пустым, а рассчитанная светимость совпадает с исходным RGB-результатом.
- Исходная книга спектра по-прежнему не изменяется.
