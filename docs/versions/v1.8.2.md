# Версия v1.8.2

Дата: 2026-07-21

Статус: стабильный GitHub Release.

## Добавлено

- В окне создания отчёта доступен выбор: полный отчёт, только ВАЯХ или только спектры.
- Свободная камера вне серии сохраняет материалы в подпапке локальной даты `YYYY-MM-DD` внутри настроенного каталога загрузок.

## Изменено

- При съёмке спектра одного пикселя виден только выбор пикселя; при последовательной съёмке подложки виден только выбор подложки и список входящих в неё пикселей.
- Частичный отчёт не сканирует и не валидирует исключённый тип измерений и не создаёт для него листы, книги или графики Excel/Origin.
- Имя выходного файла отражает выбранный состав: `report_IVL_<date>` или `report_Spctr_<date>` для частичных отчётов.

## Проверка

- Добавлены регрессионные тесты выбора состава, структуры Excel-книги, независимости частичного отчёта от отсутствующей папки измерений, видимости селекторов спектров и датированной папки свободной камеры.
- Выполняются полный набор unit/regression-тестов, синтаксическая проверка и статусный запуск приложения.

## Публикация

- Тег `v1.8.2` и стабильный GitHub Release создаются из одного проверенного коммита ветки `main`.
