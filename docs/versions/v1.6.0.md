# Версия v1.6.0

Дата: 2026-06-25

## Смысл Версии

Версия `v1.6.0` исправляет поведение спектральных измерений и улучшает рабочий экран серии: настройки измерений запоминаются, статус элемента не портится после спектров, а интерфейс освобождает место для таблиц.

## Основные Изменения

- До насыщения первой пробы на 10 мс подбор времени интегрирования спектра стартует по старой схеме. После насыщения на 10 мс включается перенос найденного безопасного `T_int` на следующие точки.
- Основные параметры ВАЯХ, спектров и стабильности сохраняются между запусками окон измерений.
- Статус работоспособности пикселя теперь изменяют только ВАЯХ и стабильность. Спектры обновляют только спектральные поля журнала.
- Спектральный Excel-файл сохраняется во время съёмки реже, чтобы уменьшить подвисания после нескольких точек.
- В окне съёмки спектров показывается максимум интенсивности и его длина волны.
- Карта статусов поднята над легендой, а нижняя лог-консоль в меню измерений удалена.

## Совместимость

Формат файлов измерений и журнала серии не менялся. В локальном `oled_app_settings.json` может появиться секция `measurement_defaults` с последними параметрами окон измерений.
