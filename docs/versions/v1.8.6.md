# v1.8.6

Дата выпуска: 2026-07-24

## Главное

- Исправлена регрессия полноразмерного фото после добавления управления ISO и выдержкой.
- Списочные параметры Canon сначала задаются через `gphoto2 --set-config-value`.
- Если камера возвращает прежнее или другое значение, сервис повторяет установку через `--set-config-index` с точным индексом исходного варианта `Choice`.
- Если оба способа не сработали, сообщение в desktop-приложении содержит название параметра, запрошенное и фактическое значения.

## Обновление Raspberry Pi

Скопируйте обновлённый `raspberry_camera_service/camera_service.py` на Raspberry Pi и перезапустите службу:

```bash
sudo systemctl restart oled-camera
sudo systemctl status oled-camera
```

После подключения desktop-приложения нажмите `Переинициализировать камеру`, повторно выберите ISO и выдержку и сделайте контрольное фото.
