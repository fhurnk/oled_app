# v1.8.7

Дата выпуска: 2026-07-24

## Главное

- В камере серии появился переключатель `Создавать отдельное видео с показаниями стабильности`.
- При включённом переключателе после завершения сопровождаемой съёмки рядом с исходным MP4 создаётся `*_telemetry.mp4`.
- На добавленной верхней полосе показываются время измерения, измеренное напряжение и измеренный ток; исходный кадр камеры не перекрывается и не обрезается.
- При достижении токового лимита на полосе появляется соответствующая отметка.
- Исходный MP4 всегда остаётся без изменений. Если объединение отключено или обработка завершилась ошибкой, исходное видео и sidecar-файлы сохраняются.

## Синхронизация

Показания читаются из итогового XLSX стабильности и привязываются к видео через существующий `_sync.json`. До первой измеренной точки показывается состояние ожидания, между точками используется последнее полученное значение.

## Зависимости

Для desktop-обработки добавлен `imageio-ffmpeg`. После обновления выполните:

```powershell
.\env\Scripts\python.exe -m pip install -r requirements.txt
```

Интернет на Raspberry Pi для создания телеметрической копии не требуется.
