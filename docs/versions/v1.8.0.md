# Версия v1.8.0

Дата: 2026-07-21

Статус: стабильный GitHub Release.

Версия `v1.8.0` завершает beta-цикл и включает проверенные изменения стабильности, камеры, спектров и отчётов.

## Стабильность

- Доступно управление по силе тока или напряжению.
- В режиме тока сохраняется программная обратная связь по измеренному току.
- В режиме напряжения новая уставка сразу подаётся на SMU без пропорционального коэффициента и ограничения шага.
- Цель можно менять напрямую или кнопками `±0.1`, `±0.25`, `±0.5`, `±1`.
- Raw CSV и XLSX сохраняют целевую уставку, реально поданное напряжение и измеренные величины.

## Камера

- Сценарий серии выполняет фото до измерения, видео вместе с ВАЯХ или стабильностью и контрольное фото после измерения.
- Медиа сохраняются отдельно в `04_CAMERA/YYYY-MM-DD/<quarter>/<substrate>/<pixel>/camera/N`; повторные сценарии за день получают следующий номер.
- Снятый перед измерением кадр показывается в основном окне и непосредственно внутри диалога `Далее`/`Отмена`; LiveView не может заменить его до продолжения.
- Для MP4 создаются `_sync.json` и `_timeline.csv`, связывающие время видео со временем измерения и событиями возможного пробоя/шунта.
- При токовом лимите стабильности SMU отключается сразу, а видео сохраняет пятисекундный post-roll.

## Спектры

- Во время подбора времени интегрирования каждая проба отображается в live-окне.
- Последнее ручное стартовое напряжение сохраняется между запусками и не заменяется напряжением открытия.
- Доступна последовательная съёмка пикселей одной подложки с продолжением, пропуском или остановкой очереди.
- Безопасная остановка завершает текущее считывание, сохраняет raw-данные и XLSX и переводит SMU на 0 В.

## Отчёты И Интерфейс

- Спектры для отчёта сгруппированы по подсериям и подложкам; выбирается одна подложка и один её спектральный пиксель.
- Формулы Origin-отчёта используют прямые ссылки на колонки `Sheet1`.
- Карта подложкодержателя соответствует физическому расположению образцов.

## Проверка

- Успешно проходят 62 автоматических unit/regression-теста.
- Синтаксис модулей и статусный запуск приложения проверяются перед публикацией.
- Canon, Raspberry Pi, Ossila и спектрометр требуют контрольной проверки на реальном стенде.

## Публикация

- Сетевые операции GitHub выполняются вне ограниченного sandbox Codex с доступом к системному keyring.
- Тег `v1.8.0` и GitHub Release создаются из одного проверенного коммита ветки `main`.
