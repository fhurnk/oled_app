# Версия v1.5.5

Дата: 2026-06-25

## Смысл Версии

Версия `v1.5.5` добавляет в проект встроенный способ создавать GitHub Releases без ручного открытия веб-интерфейса.

## Основные Изменения

- Добавлен `scripts/create_github_release.py`.
- Release можно создать командой:

```powershell
.\env\Scripts\python.exe .\scripts\create_github_release.py v1.5.5
```

- Если установлен GitHub CLI, скрипт использует `gh release create`.
- Если GitHub CLI недоступен, скрипт использует GitHub REST API и токен из `GITHUB_TOKEN` или `GH_TOKEN`.
- `AGENTS.md` и `docs/GITHUB_RELEASE_WORKFLOW.md` обновлены, чтобы будущие чаты Codex создавали GitHub Release для каждой версии через этот скрипт.

## Совместимость

Формат файлов измерений, журналов и настроек приложения не менялся.
