# Версия v1.7.5

Дата: 2026-06-30

## Смысл Версии

Версия `v1.7.5` продолжает перенос приложения в новый модульный каркас и подготавливает report-слой в `oled_app/reports/`. Референсное приложение `oled_measurement_app_v2_5.py` не меняется.

## Основные Изменения

- Логика подготовки Origin-отчета подготовлена в `oled_app/reports/origin_report.py`.
- `scripts/build_report_origin_workbook.py` оставлен совместимой CLI-оболочкой и вызывает новый модуль.
- `oled_app/reports/__init__.py` экспортирует основные функции report-слоя.
- `oled_app/main.py` показывает, что слой `reports` уже подготовлен.
- `docs/modularization_plan.md` отмечает этап 5 `reports/` как выполненный.

## Совместимость

Старый CLI-запуск `scripts/build_report_origin_workbook.py` сохраняется. GUI может продолжать запускать этот скрипт через `subprocess`, а новый модульный каркас получает прямой Python API для будущего подключения отчетов.
