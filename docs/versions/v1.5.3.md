# Версия v1.5.3

Дата: 2026-06-25

## Смысл Версии

Версия `v1.5.3` исправляет классификацию пикселей при ВАЯХ, когда измерение остановилось по обычному лимиту тока, но ток не достиг порога пробоя/сгорания.

## Основные Изменения

- Пиксель без фототока, у которого есть ток и который дошёл до лимита измерения, теперь получает статус `NONWORKING`, если ток ниже порога пробоя/сгорания.
- Статус `BURNED` используется только для пикселя, сгоревшего или пробившегося по току во время съёмки.
- Финальный статус серии циклов и текстовое описание первого промера больше не трактуют `current_limit_reached` как сгорание.
- В расширенных настройках ВАЯХ оставлен явный параметр `Ток пробоя/сгорания, мА` как критерий для `BURNED`.

## Совместимость

Формат файлов измерений и журнала серии не менялся. Старые настройки открываются, но достижение обычного лимита тока больше не переводит пиксель в `BURNED` без достижения порога пробоя/сгорания.
