# Версия v1.7.7

Дата: 2026-06-30

## Смысл Версии

Версия `v1.7.7` продолжает перенос слоя `measurements/` и подготавливает workflow спектров в новом модульном пакете. Референсное приложение `oled_measurement_app_v2_5.py` не меняется.

## Основные Изменения

- Добавлен `oled_app/measurements/spectrum.py` с параметрами `SpectrumParams`, helper-классом `SpectrumHelper`, подбором времени интегрирования, обработкой raw/dark/baseline-corrected спектров и сохранением Excel-книги.
- Новый spectrum workflow использует подготовленные слои `oled_app.hardware` и `oled_app.utils`.
- `oled_app/measurements/__init__.py` экспортирует основные spectrum API.
- `oled_app/main.py` показывает, что подэтап `measurements.spectrum` уже подготовлен.
- `docs/modularization_plan.md` отмечает спектры как выполненную часть этапа `measurements/`; стабильность остается отдельным следующим подэтапом.

## Совместимость

Старый GUI и референсный файл остаются нетронутыми. Новый spectrum-модуль подготовлен для будущего подключения модульного GUI и может проверяться отдельно от монолита.
