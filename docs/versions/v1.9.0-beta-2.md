# v1.9.0-beta-2

Дата выпуска: 2026-07-30

## Главное

Исправлено построение миниатюр ВАЯХ на карте пикселей. Раньше ток OLED переводился в логарифмическую шкалу, а ток OLED и фототок независимо растягивались на всю высоту изображения. Из-за этого миниатюра визуально не совпадала с правильным графиком в итоговом XLSX.

## Новое Отображение

- ток OLED и ток фотодетектора строятся в линейном масштабе;
- обе кривые используют одну общую шкалу, поэтому сохраняется их реальное взаимное соотношение;
- цвета соответствуют live-графику измерения:
  - ток OLED — синий `#0B61A4`;
  - ток фотодетектора — красный `#C43C30`;
- числовые подписи по-прежнему скрыты, поскольку миниатюра нужна для быстрой оценки формы ВАЯХ.

## Обновление Старых Миниатюр

- В PNG сохраняется версия алгоритма рендера.
- При наведении приложение распознаёт миниатюру старого формата и один раз пересоздаёт её из последнего XLSX.
- После обновления сохраняется прежнее правило: один перезаписываемый файл на пиксель в подпапке `thumbnails`.
- Если XLSX временно открыт с блокировкой чтения, прежняя картинка остаётся доступной, а обновление повторяется при следующем наведении.

## Проверка

- Исправленная миниатюра построена по 251 точке raw CSV измерения `CLB2_1_1`.
- Максимумы исходных данных: `I OLED = 7,851 мА`, `I PD = 12,72 мкА`; на общей шкале фототок правильно отображается выше тока OLED.
- `python -m compileall -q oled_app tests`
- `python -m unittest discover -s tests -v`
- 117 тестов проходят в окружении `env`.
