# Версия v1.7.3

Дата: 2026-07-02

## Смысл Версии

`v1.7.3` исправляет первые замечания после перехода на модульный интерфейс: возвращает проверку оборудования на стартовый экран, восстанавливает прокрутку колесом мыши в прокручиваемых окнах и уточняет построение IVL-графиков в Origin-отчете.

## Исправлено

- На стартовом экране модульного GUI снова показывается состояние оборудования и автоматически запускается проверка SMU/спектрометра.
- Общий helper прокручиваемых окон снова обрабатывает колесо мыши при наведении на область содержимого.
- IVL-записи отчета сортируются по физическому порядку пикселей: номер четверти, номер подложки, номер пикселя.
- Графики Origin после добавления всех кривых явно обновляют легенду, чтобы в ней появлялись все серии.

## Совместимость

Форматы журналов, папок измерений и Excel-файлов не меняются. Референсный файл `oled_measurement_app_v2_5.py` не изменялся; исправления внесены в модульный GUI и модуль подготовки отчета.
