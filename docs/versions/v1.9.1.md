## Автоматическое Подключение Камеры К Wi-Fi

В `Настройки → Камера` можно включить автоматическое подключение к сети Raspberry Pi. Для работы нужно один раз подключиться к этой сети штатными средствами Windows, чтобы профиль уже был сохранён в системе, а затем указать его имя в приложении.

При открытии камерного окна приложение:

1. сначала проверяет доступность сервиса через текущую сеть;
2. если сервис недоступен, подключает Windows к указанному сохранённому профилю через `netsh wlan`;
3. ожидает готовности HTTP-сервиса Raspberry Pi;
4. при закрытии камеры возвращает прежний профиль, если эта настройка включена.

Можно явно задать Wi-Fi-адаптер или оставить поле пустым для автоматического выбора. В настройках также доступен тайм-аут подключения. Пароль сети не считывается и не сохраняется приложением.

## Настройки Интегрального Пересчёта

В окне выбора четвертей для интегральной калибровки добавлены два процента:

- допустимое отклонение значения интеграла от медианы;
- минимальная доля измерений вне этого диапазона для рассмотрения линейной модели.

Если доля отклонений меньше второго порога, используется медиана точек внутри допуска. Если порог достигнут, приложение проверяет наличие систематического изменения интеграла по напряжению и при подтверждении строит `integral(V) = a × V + b`. При отсутствии систематического тренда применяется робастная медиана.

Оба порога, фактическая доля точек вне допуска и выбранная модель сохраняются в файлах калибровки и результирующем XLSX.

## Устойчивое Определение Напряжения Открытия

В `Настройки → ВАЯХ доп.` доступны независимые параметры:

- `Порог открытия по фототоку, мкА`;
- `Следующих точек для подтверждения открытия`.

Алгоритм находит первое измерение, в котором ток фотодиода достиг или превысил порог. Эта точка принимается как напряжение открытия только тогда, когда заданное число следующих точек подряд также остаётся не ниже порога. Например, при значении `5` проверяется кандидат и ещё пять следующих измерений.

Это исключает ложное открытие по одиночному всплеску. Подтверждённое значение автоматически сохраняется в журнал и XLSX. Если пиксель признан рабочим, но до конца ВАЯХ не набралось устойчивой последовательности, приложение предлагает задать напряжение вручную.

Порог рабочего фототока, используемый для статуса пикселя, остаётся отдельной настройкой и не смешивается с новым порогом открытия.
