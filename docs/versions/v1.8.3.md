# Версия v1.8.3

Дата: 2026-07-22

Статус: стабильный релиз.

## Исправлено

- При кратковременном отказе файлового фильтра OneDrive чтение только что сохранённого JPEG автоматически повторяется с небольшой задержкой.
- Полноразмерный JPEG после съёмки сначала полностью считывается в память, а затем декодируется и уменьшается для окна подтверждения `Далее`/`Отмена`.
- Pillow больше не удерживает и не читает лениво только что сохранённый файл из синхронизируемой папки OneDrive, что устраняет ошибку `[Errno 22] Invalid argument` в предпросмотре.

## Изменено

- Порядок LiveView оставлен как в `v1.8.2`: поток запускается и останавливается отдельными кнопками камеры, а открытие параметров ВАЯХ или стабильности не включает его автоматически.
- Из заголовков свободной камеры и камеры серии удалена пометка `BETA`.
- Вкладка `Камера beta` в настройках переименована в `Камера`.

## Проверка

- Камерные unit/regression-тесты проверяют повтор чтения после временной ошибки OneDrive и декодирование JPEG из независимого снимка файла в памяти, в том числе при имитации `OSError(22)`.
- Проверяется, что окно параметров измерения открывается без автоматического запуска LiveView.
- Поиск по модульному интерфейсу камеры подтверждает отсутствие пользовательских надписей `beta`.

## Публикация

- Тег `v1.8.3` и GitHub Release должны быть созданы из одного проверенного коммита ветки `main`.
