# Версия v1.7.6

Дата: 2026-07-02

## Смысл Версии

`v1.7.6` возвращает создание серии к виду журнала подложкодержателя, добавляет редактирование серии и связывает цвет серии с именами четвертей и коэффициентами светимости.

## Добавлено

- Экран создания/редактирования серии с визуальным предпросмотром подложкодержателя, пикселей и динамических имен.
- Короткое описание для каждой четверти серии.
- Единый цвет светодиодов для всей серии: красный, зеленый или синий.
- Отдельные коэффициенты перевода фототока в светимость для `R/G/B`.
- Кнопка `Настройки серии` в меню открытой серии.

## Изменено

- Имя четверти формируется из базового имени и суффикса общего цвета серии: `C` + красный = `CR`.
- При измерениях ВАЯХ, спектров и стабильности используется коэффициент яркости, соответствующий цвету серии.
- Окна приложения открываются шире и лучше подгоняются под содержимое по горизонтали.

## Совместимость

Старые серии с `quarter_names` продолжают открываться. При редактировании старой серии приложение преобразует сохраненное имя вида `CR` в базу `C` и общий цвет `R`, чтобы после сохранения имя не удваивало суффикс.
