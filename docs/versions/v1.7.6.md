# Версия v1.7.6

Дата: 2026-06-30

## Смысл Версии

Версия `v1.7.6` начинает перенос слоя `measurements/` и подготавливает workflow ВАЯХ/IVL в новом модульном пакете. Референсное приложение `oled_measurement_app_v2_5.py` не меняется.

## Основные Изменения

- Добавлен `oled_app/measurements/ivl.py` с параметрами `IVLParams`, циклом измерения, определением статуса пикселя, поиском напряжения открытия и сохранением IVL Excel-книги.
- Новый IVL workflow использует подготовленные слои `oled_app.hardware` и `oled_app.utils`.
- `oled_app/measurements/__init__.py` экспортирует основные IVL API.
- `oled_app/main.py` показывает, что подэтап `measurements.ivl` уже подготовлен.
- `docs/modularization_plan.md` отмечает ВАЯХ/IVL как выполненную часть этапа `measurements/`; спектры и стабильность остаются отдельными следующими подэтапами.

## Совместимость

Старый GUI и референсный файл остаются нетронутыми. Новый IVL-модуль подготовлен для будущего подключения модульного GUI и может проверяться отдельно от монолита.
