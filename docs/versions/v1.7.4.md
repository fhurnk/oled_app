# Версия v1.7.4

Дата: 2026-07-02

## Смысл Версии

`v1.7.4` улучшает рабочий процесс модульного GUI после первых проверок: делает имя отчета зависимым от дат измерений, упрощает окно ВАЯХ, сохраняет текущий экран после изменения настроек и исправляет прокрутку вложенных таблиц.

## Изменено

- Файл отчета по умолчанию называется по датам ВАЯХ и спектров: `report_YYYY-MM-DD.opju`, если даты совпадают, или `report_IVL_YYYY-MM-DD_Spctr_YYYY-MM-DD.opju`, если они разные.
- Поле COM-порта удалено из окна ВАЯХ; порт задается в общих настройках или выбирается через авто-COM.
- После сохранения настроек приложение закрывает окно настроек и остается на том экране, из которого настройки были открыты.

## Исправлено

- Таблицы с историей ВАЯХ и последними датами/метриками теперь прокручиваются колесом мыши при наведении на них, не прокручивая основное окно измерений OLED.

## Совместимость

Форматы журналов, папок измерений, Excel-файлов и Origin-отчетов не меняются. Референсный файл `oled_measurement_app_v2_5.py` не изменялся.
