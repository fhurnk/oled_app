# v2.0.0-alpha

Дата первого checkpoint: 2026-07-30

Канал: prerelease

Стабильная база: `v1.9.1`

## Политика Alpha

Все этапы перехода на v2 накапливаются в одном GitHub Release и теге
`v2.0.0-alpha`. Отдельные версии `alpha-2`, `alpha-3` и последующие не создаются.
Этот файл, changelog, тег и prerelease обновляются после каждого проверенного
checkpoint до завершения перехода или отдельного решения пользователя.

Рабочее Tkinter-приложение остаётся штатным:

- `oled_modular_app.py` продолжает быть основным входом;
- `oled_measurement_app_v2_5.py` остаётся нетронутым референсом;
- будущие launcher/backend/frontend v2 добавляются отдельным контуром;
- переключение основного входа запрещено до функционального соответствия,
  аппаратной проверки и отдельного решения пользователя.

## Checkpoint 1 — Фиксация Поведения

- Начато выполнение `docs/v2_interface_plan.md`.
- Добавлен `docs/v2_functional_parity_checklist.md` с матрицей всех рабочих
  экранов и действий v1.9.1.
- Зафиксированы значения по умолчанию основных и расширенных параметров ВАЯХ,
  спектров, стабильности, камеры, оборудования, единиц и хранения raw CSV.
- Описаны переходы между экранами, условия доступности workflow, ошибки и решения
  оператора для `NO_CONTACT`, `CURRENT_LIMIT`, ручного opening voltage,
  стабильности, камеры и безопасной остановки.
- Зафиксированы совместимые контракты `series_config.json`,
  `series_journal.xlsx`, raw CSV и итоговых XLSX.
- Определены 12 golden-сценариев для сравнения Tkinter и v2 без добавления
  пользовательских серий измерений в git.
- Добавлен `docs/v2_migration_status.md` с этапами, защитой основного приложения и
  решениями, которые нужно подтвердить перед техническим прототипом.

## Checkpoint 2 — Технический Прототип

- Добавлен отдельный `oled_v2_app.py`; штатный `oled_modular_app.py` продолжает
  запускать Tkinter.
- Реализован FastAPI backend на случайном порту `127.0.0.1` с lifecycle,
  session token, проверкой `Host`/`Origin` и одним управляющим клиентом.
- Реализован светлый React/Vite-экран обзора, который читает версию, состояние
  backend, режим оборудования и статус миграции.
- Production assets собираются в `oled_v2/static/` и входят в desktop-сборку,
  поэтому Node.js не требуется на лабораторном ПК.
- pywebview открывает frontend в отдельном WebView2-окне с минимальным размером
  `1180×720`.
- Добавлены ротация логов в `%LOCALAPPDATA%\OLED Measurement App\logs`,
  `requirements-v2.txt`, build-скрипты и PyInstaller `onedir`-спецификация.
- Подготовлена и проверена отдельная `onedir`-сборка размером 24 МБ. Основной
  Tkinter-дистрибутив и reference-файл не переключались.

## Единый Обновляемый GitHub Release

`scripts/create_github_release.py` получил `--update-existing`: первая публикация
создаёт prerelease, а последующие обновляют тот же релиз. Для каждого следующего
checkpoint тег `v2.0.0-alpha` передвигается на последний проверенный commit.
