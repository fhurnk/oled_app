# v1.8.8

Дата выпуска: 2026-07-24

## Главное

- Строка `Качество/размер камеры` появляется только при наличии соответствующего изменяемого списка в возможностях камеры.
- Строка `Кадров в секунду камеры` появляется только если камера предоставляет отдельный выбор FPS.
- Недоступные видеонастройки полностью скрываются, как отдельные неподдерживаемые параметры ISO или выдержки.
- Фактические разрешение и частота LiveView остаются в информационной строке, даже если управлять ими с компьютера нельзя.

Изменения затрагивают desktop-интерфейс; обновлять сервис Raspberry Pi не требуется.

## Хотфикс 2026-07-25

- При `WriteFile failed` или другой ошибке COM-порта во время стабильности приложение закрывает повреждённое соединение и до четырёх раз повторно подключается к SMU, отправляя 0 В и отключение обоих каналов.
- Успешный аварийный сброс явно указывается в сообщении об остановке. Если команды не приняты, пользователь получает критическое требование отключить выход прибора вручную.
- Телеметрическая полоса теперь показывает `U уст.`: целевое напряжение для режима удержания напряжения либо программно подаваемое напряжение для режима удержания тока. Измеренное значение напряжения больше не используется в подписи видео.
