# v1.8.8

Дата выпуска: 2026-07-24

## Главное

- Строка `Качество/размер камеры` появляется только при наличии соответствующего изменяемого списка в возможностях камеры.
- Строка `Кадров в секунду камеры` появляется только если камера предоставляет отдельный выбор FPS.
- Недоступные видеонастройки полностью скрываются, как отдельные неподдерживаемые параметры ISO или выдержки.
- Фактические разрешение и частота LiveView остаются в информационной строке, даже если управлять ими с компьютера нельзя.

Изменения затрагивают desktop-интерфейс; обновлять сервис Raspberry Pi не требуется.
