# v1.8.5

Дата выпуска: 2026-07-24

## Главное

- В окне `Составить отчёт` можно исключить одну или несколько физических четвертей держателя флажками `1–4`.
- Исключение применяется ко всему выбранному составу отчёта: ВАЯХ, спектрам, таблицам и графикам Origin/Excel.
- Исключённые четверти отбрасываются до чтения измерений и проверки спектрального выбора, поэтому строгий режим не требует для них подложку или пиксель.
- Для автоматизации доступен повторяемый аргумент CLI `--exclude-quarter N`.

## Использование

1. Откройте серию и нажмите `Составить отчёт`.
2. В блоке `Исключить четверти из отчёта` отметьте номера, которые не должны попасть в результат.
3. Настройте оставшиеся параметры и нажмите `Составить отчёт`.

Пример CLI:

```powershell
.\env\Scripts\python.exe .\scripts\build_report_origin_workbook.py `
  --measurements-dir .\OLED_series\<series>\measurements `
  --exclude-quarter 2 `
  --exclude-quarter 4 `
  --output .\report.opju
```
