# v1.9.0-beta-3

Дата выпуска: 2026-07-30

## Быстрый Спектральный Пересчёт

Чтение листов `Сводка` и `Processed counts per s` переведено на один последовательный проход. Раньше приложение в режиме `read_only` тысячи раз обращалось к отдельным ячейкам большого XLSX, из-за чего XML листа перечитывался снова и окно выглядело зависшим.

На книге пикселя `2026-07-29_Blue / CB1_2_1` теперь:

- считываются все 8 точек при напряжениях от 3,25 до 5 В;
- вычисляется медианный спектральный интеграл `100,004954`;
- полный цикл чтения, калибровки и записи отдельного XLSX занимает около 0,15 с на диагностической копии.

## Выбор Четвертей

После нажатия кнопки спектрального пересчёта открывается таблица из четырёх строк:

- у каждой четверти есть собственный флажок;
- для каждой включённой четверти выбирается один пиксель-калибратор;
- в списке доступны только пиксели, для которых сохранён спектр;
- все доступные четверти по умолчанию отмечены;
- кнопки `Выбрать все доступные` и `Снять выбор` управляют группой целиком.

Каждая четверть создаёт собственный `SPECTRAL_RECALC_*.xlsx` рядом с исходным спектром. Ошибка чтения или отмена замены уже сохранённой калибровки для одной четверти не прерывает остальные выбранные расчёты.

## Проверка

- Последовательное чтение защищено тестом, запрещающим случайный доступ `ReadOnlyWorksheet.cell`.
- Проверены группировка пикселей по четвертям и продолжение пакетной обработки после ошибки одного спектра.
- Диагностический XLSX проверен на отсутствие ошибок формул и визуально: таблица и обе диаграммы отображаются корректно.
- `python -m compileall -q oled_app tests`
- `python -m unittest discover -s tests -v`
- Все 119 автоматических тестов проходят в окружении `env`.
