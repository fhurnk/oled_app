# Версия v1.5.6

Дата: 2026-06-25

## Смысл Версии

Версия `v1.5.6` делает документацию проекта понятной не только человеку, но и будущим чатам Codex: добавляет короткую карту проекта и структурированный manifest с текущей версией, путями и release-workflow.

## Основные Изменения

- Добавлен `CODEX_PROJECT.md` с краткими правилами чтения проекта, точками входа, workflow измерений и release-процессом.
- Добавлен `docs/project_manifest.json` как машинно читаемый manifest проекта.
- `AGENTS.md` теперь явно указывает порядок чтения файлов для новых Codex-чатов.
- Правила версии дополнены: при каждом релизе нужно обновлять `CODEX_PROJECT.md` и `docs/project_manifest.json`.

## Совместимость

Формат файлов измерений, журналов и настроек приложения не менялся.
