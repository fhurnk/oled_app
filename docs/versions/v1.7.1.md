# Версия v1.7.1

Дата: 2026-06-29

## Смысл Версии

Версия `v1.7.1` уточняет подготовку отчетов по датам измерений, упрощает окно выбора напряжений и добавляет опциональную автонастройку COM-порта Ossila.

## Основные Изменения

- В окне `Составить отчет` можно выбрать дату ВАЯХ и дату спектров отдельно.
- `scripts/build_report_origin_workbook.py` поддерживает аргументы `--ivl-date` и `--spectrum-date`.
- Список спектральных пикселей перестраивается при смене даты спектров.
- Индивидуальные поля диапазона напряжений показываются только при выключенном общем диапазоне и шаге.
- В настройках появилась опция `Автонастройка COM порта Ossila`.
- При включенной автонастройке приложение ищет доступный COM-порт через `pyserial` и проверяет кандидатов через `xtralien`.
- Статус оборудования показывает только краткие состояния Ossila/xtralien и спектрометра.
- Добавлен предрелизный план разбиения приложения на модули: `docs/modularization_plan.md`.

## Совместимость

Форматы журналов и файлов измерений не меняются. Если автонастройка COM-порта выключена или порт не найден, используется прежнее ручное значение COM-порта.
